# Gallery provenance

The source still life was generated with OpenAI Imagegen on 2026-08-15 for this repository. It uses large matte shapes and quiet negative space so analog defects remain easy to compare.

`vhs-classic.webp`, `crt-tv.webp`, and `security-cam.webp` were rendered from `source.webp` by the locally compiled `comfyui_ntsc_rs` CPython 3.13 extension with repository presets and random seed `23`. They are product output, not simulated overlays.
