# Gallery provenance

The source still life was generated with OpenAI Imagegen on 2026-08-15. Large matte shapes and quiet negative space make analog defects easy to compare.

`vhs-classic.webp`, `crt-tv.webp`, and `security-cam.webp` were rendered from `source.webp` by the locally compiled `comfyui_ntsc_rs` CPython 3.13 extension. They used repository presets and random seed `23`. These frames are product output, not simulated overlays.
